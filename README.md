# Aram Najarian — Portfolio

A static portfolio site built with plain HTML, CSS, and JavaScript — no build step required.

## Pages

- **Home** — Hero section with portrait and intro
- **Portfolio** — Project gallery (MĪRA, DrumStar Kit 1, River Gauge) with expandable detail panels
- **Resume** — Download link for PDF resume
- **Background & Motivation** — About section

## Setup

1. Add `Aram_Najarian_Resume.pdf` to the repo root for the resume download to work.
2. Enable GitHub Pages: **Settings → Pages → Branch: main → Folder: / (root)**.

The site will be live at `https://aramnajarian23.github.io/Portfolio/`.
